## Descripción

Programa en Python que usa la teoría de grafos para:

- Recorrido en anchura (BFS), con el nodo inicial indicado por el usuario.
- Recorrido en profundidad (DFS), con el nodo inicial indicado por el usuario.
- Buscar vértice (retorna verdadero o falso).
- Distancia entre dos nodos, sumando los pesos del camino encontrado con el recorrido en anchura.

## Archivos

- `grafo.py`: clase `Grafo` con todos los métodos.
- `menu_principal.py`: menú del programa.

## Cómo ejecutar

```bash
python menu_principal.py
```
